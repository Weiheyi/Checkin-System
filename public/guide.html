💡 使用说明

这个站点用来记录每天的学习、管理背单词和打卡。第一次用，看第一节「三分钟上手」就够； 其余几节按需查即可。

① 三分钟上手 ② 打卡与任务 ③ 背单词 ④ 学习工具 ⑤ 好友与排行榜 ⑥ 个人中心与反馈 ⑦ 常见问题 🔗 友情链接

① 三分钟上手

  1. 打开 打卡 页，写一句今天打算学什么，点「打卡」。每天只能打一次； 不打也行——当天学习累计满 5 个不同单词会自动打卡。
  2. 在下面添加今天要做的事（例如「背 50 个单词」），做完打勾。
  3. 去 工具 → 📖 背单词，点「＋ 新建」，把单词表粘贴进去（或上传文件）保存。
  4. 点进这个单词本开始背诵或考核。一轮结束后，系统会自动往今天的任务里记一条并算作完成； 当天还没打卡、且累计已学满 5 个词时，会先自动打卡再记任务。

所以「完成任务 / 完成率」不会一直是 0 了——学习满 5 个词会自动打卡，任务才有地方记。

② 打卡与任务

  • 打卡：每人每天一条，重复点会提示「今天已经打卡过了」。打卡会累计「连续天数」， 中断一天后从 1 重新算。
  • 任务：在打卡后添加，可勾选完成 / 取消，也能删除。
  • 学习自动记任务：一轮背诵、考核或消灭错词结束时，会自动加一条已完成的任务，例如 「📖 背单词：SAT（30 个）」「📝 考核：SAT（20 题 · 正确率 80%）」。 当天没打卡的话就跳过，不会报错。
  • 学习满 5 个词自动打卡：当天累计学到 5 个不同单词（背诵、考核、灭错都算，答对答错都算） 就自动补一条打卡，不用手动点；已经打过卡就跳过。打卡内容形如 「📚 学习打卡：今日已学习 N 个单词」。
  • 学习统计：连续天数、打卡天数、完成任务数、完成率，都在打卡页顶部。
  • 打卡历史：往下看能看到最近每天的打卡与任务完成进度。

③ 背单词

新建单词本

  • 把单词表粘贴进文本框即可，格式很宽松，会自动识别： apple 苹果、apple,苹果、apple - 苹果、 apple | 苹果、apple：苹果、Tab 分隔、行首序号（1. apple 苹果）、 abandon vt. 放弃，中文在前（苹果 apple）也能认。
  • 也可以上传文件或直接拖进文本框：支持 PDF、Word（.docx）、图片（OCR 识别）、txt。 解析全在本地完成，文件不会上传到任何服务器。
  • 保存前可点「预览」核对、点「交换中英」纠正顺序；重复单词只保留第一条。
  • 排列顺序可选「文件顺序」或「字母顺序」；之后在单词列表页也能随时切换显示排序。

单词列表

  • 顶部可按状态筛选：全部 / 错词 / 未背 / 认识 / 模糊 / 不认识，数字是各状态的数量。
  • 搜单词：列表上方的搜索框输入词（或词的一部分、中文释义都行），直接告诉你 「在第几页」并跳过去、把那行标出来；命中多个可以按回车或点「下一个」逐个看。 搜索是在当前筛选的结果里定位，所以报出的页码和列表显示的完全一致。
  • 分页每页 20 / 50 / 100 条（会记住你的选择）；也能直接在「跳至 __ 页」输入页码跳过去。
  • 勾选若干单词后点「全选本页」只选当前页；再点「考核选中」就会跳到考核设置页， 范围自动变成「选中 N」、题量自动等于选中的数量，你确认题型后点「开始考核」即可。

背诵

  • 点卡片翻开释义，再选 认识 / 模糊 / 不认识。
  • 可以勾选「随机顺序」和「自动发音」；卡片上有音标，点 🔊 听美式发音。

考核

  • 题型：选择（看词选义 / 看义选词）、拼写（看义拼词）、 填义（看词写中文意思，自动判分）。
  • 范围：全部 / 未背 / 认识 / 模糊 / 不认识，或「选中 N」（上面说的考核选中）。
  • 题量：10 / 20 / 50 / 全部，也可以填「自定义题量」。
  • 计时与限时：开考就开始计时，题目上方显示已用时间，结束后结果里有「用时」。 可选的「每题 10 秒」限时默认关闭，开了就每题独立倒计时，超时按答错算。
  • 填义题判分：自动比对，命中释义里任意一个义项就算对；连内置词典里同一个词的 其它义项也算对（所以答近义词常常也能过）。判错时会给一个「我答对了，算对」按钮， 点了就按答对算；点错了不用慌——按钮会变成「点错了，改回算错」，可以来回点， 真正的记分留到点「下一题」的时候，所以在「下一题」之前怎么点都不会算数。

错词灭错

  • 「错词」页专门收拾答错过的词：答错过的词会进错词池，点「开始消灭错词」反复练， 连续答对 2 次就算消灭。
  • 答对一次熟练度 +1，答错清零并排到队尾继续练；中途可「结束本轮」。
  • 消灭之后这些词不会消失——在单词列表的「错词」筛选里仍然能看到，并标着「已消灭」。

学习记录

  • 单词本列表右上角「📅 学习记录」：顶部是今日概览（今天背了多少、考核多少、正确率）， 下面按天汇总。点任意一条会进入这条记录的详情页，看到具体背了哪些单词、每个词的结果。
  • 详情页右上角「📄 下载 PDF」可以只导出这一条记录：点完在浏览器的打印窗口里把 「目标打印机」选成「另存为 PDF」再保存就行（手机上是在分享里选「打印」→ 存到文件）。 左上角「返回」回到学习记录列表。
  • 导出全部 PDF：记录列表右上角「📄 导出 PDF」会把当前范围的记录排成一份文档，操作方式和上面一样。 文档包含三块：总览、错词表（每个答错过的词错了几次、对了几次、最近一次结果和时间、属于哪个单词本， 按错误次数从多到少排）、按天的学习记录（每次背诵/考核的汇总 + 逐词明细，答错的词会标红）。 导出范围跟上面的筛选一致（全部 / 背诵 / 考核）。
  • 旁边的「⬇ CSV」是同一份错词表，导出成表格文件，方便自己用 Excel 统计。

④ 学习工具

  • 进入「工具」页会先看到五个功能的卡片，点哪个才打开哪个；左上角「← 全部工具」可以返回。
  • ⏱ 计时器：正计时，支持计次；切到别的页面也不会停。
  • ⏳ 倒计时：选 5 / 25 / 45 / 60 分钟或自定义，到点响铃提醒。
  • 📖 背单词：就是上一节的内容。
  • 🔤 字典：输入英文单词，显示美音音标 + 中文释义，点 🔊 可朗读。 内置约 12.5 万条音标和 5.9 万条中文释义，完全离线（第一次打开要加载约 6MB，之后就快了）。
    查到的词可以点 「＋ 加入生词本」直接收进单词本：会弹窗让你挑一本， 同一个词不会重复添加；离线时也能加，先记在本机、联网后自动补传。

词汇量测试

  • 内置词表按词频切成 20 个频段，每档随机抽几个词：先只看单词判断认不认识 （这一步不给释义，不然等于送答案），答完再把你勾了「认识」的词连同释义列一遍， 没真认识的把勾去掉即可，估算按去掉之后的算。
  • 估算 = 各档「词数 × 该档认识比例」相加，并给出大概的浮动范围。题量可选 60 / 100 / 140 题，题量越大范围越窄。结果是抽样估出来的， 不用跟别的网站测出来的数字精确对齐。
  • 结果存到云端，介绍页下方能看到历史记录（含与上一次的差值），也可以删除。
  • 词表是内置的约 2.6 万个常用词，所以估算上限就是这 2.6 万；生僻词、专有名词不在范围内。 第一次进入要先加载词库（约 6MB），加载过一次之后就快了。

⑤ 好友与排行榜

  • 在「好友」页输入对方注册用的邮箱即可精确添加（对方不需要同意）。
  • 可以看到好友的打卡动态、给动态点赞；「排行榜」按打卡天数 / 连续天数 / 完成任务数 PK。
  • 私信：切到「私信」分段，会列出所有好友的会话（最后一条消息 + 未读数）， 点进某位好友就能一对一聊天。对方发来的未读会在「私信」上显示小红点，打开会话即标记已读、 红点随之减少；只能给好友发消息。
  • 动态评论：每条动态下面的「💬 N」点开就是评论区，写上内容点「发送」即可； 评论带昵称 / 头像，自己的评论旁边有「删除」。
  • 好友之间只能看到打卡与任务（以及你愿意发的私信、评论），单词本、学习记录、反馈都是私密的。
  • 私信和评论都需要联网，没有实时推送：进入分段 / 会话时拉取最新，自己发完消息即时上屏。

⑥ 个人中心与意见反馈

  • 「我的」页可以改头像、昵称、个性签名，看自己的数据总览，并在这里修改密码。
  • 🎨 外观：可上传头像图片（会盖过选的 emoji），以及 电脑端背景与手机端背景——两张分开传，宽屏用横图、窄屏用竖图， 手机端不传就沿用电脑端那张。上传时都会先让你拖动 + 缩放裁剪。
  • 背景透明度控制背景图本身的浓淡；界面透明度控制卡片面板的浓淡， 调低后背景就透出来，文字依然是清楚的。
  • 主题支持浅色 / 深色 / 跟随系统；右上角的 🌙 按钮可以快速切换。
  • 界面样式可以换配色：默认 / 晚霞 / 大海 / 森林 / 樱粉，浅色与深色各有一套。
  • 💬 意见反馈：写下用得不顺手的地方或想要的功能（联系方式可选），提交后能在下方 看到自己提交过的历史记录，也可以删除。

⑦ 常见问题

  • 我背了单词，为什么完成率还是 0？
    任务挂在当天打卡记录下。当天累计学到 5 个不同单词会自动打卡并把这一轮记入任务； 不足 5 个词时还没有任务，先在「打卡」页手动打一次卡即可。
  • 数据存在哪里？安全吗？
    存在 Supabase（Postgres）里，账号密码和数据都只有你自己能读写；好友只能看到打卡与任务。
  • 换手机 / 换浏览器怎么办？
    用同一个邮箱密码登录即可，数据都在云端，不用迁移。
  • 上传的单词表会上传到哪里吗？
    不会。PDF / Word / 图片的解析全部在你的浏览器里完成，文件不出本机。
  • 字典里查不到某个词？
    中文词库只收了约 5.9 万个常用词，音标词典约 12.5 万条；生僻词、地名、人名大多不在范围内。
  • 第一次打开字典很慢？
    首次要加载约 6MB 词库，加载过一次后就完全离线、秒出。
  • 忘记密码了？
    站点不依赖邮件，暂时没法自助找回，请联系站长重置。
  • 断网了还能用吗？
    能。页面靠浏览器存的离线副本打开；数据靠「离线模式」——断网时会自动按离线处理， 打卡、任务、背单词、词汇量测试照常操作，改动先存在本机，联网后自动补传。
    顶部会出现一条横幅写着「N 项待同步」，点上面的按钮就能切回在线并补传； 也可以去「我的 → ⚙️ 设置 → 离线模式」手动切换（比如知道要断网了，提前切过去）。
    两个注意点：离线数据只存在这台设备上（换设备或清浏览器数据就没了）； 登录、好友、私信、评论、新建 / 删除单词本、上传图片这些必须联网，离线时会明确提示。
    另外「字典」和「词汇量测试」的约 6MB 词库是「用到时才缓存」， 要联网打开过一次之后才离线可用。
  • 离线时单词本是空的？
    离线缓存只由「联网时成功读过的内容」填充，所以先在联网状态下打开「工具」页 （进去一次就行），后台会自动把单词本内容和学习记录存一份，之后断网也能直接打开来背。
    如果离线时看到「本地还没有这部分数据」，按顶部横幅上的按钮切回在线即可。
  • 手机上怎么看？
    直接用手机浏览器打开即可，底部有导航栏；也可以「添加到主屏幕」当 App 用， 装好之后断网也能打开。
